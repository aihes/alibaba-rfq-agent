这个浏览器可以做什么？

已支持
Alibaba 登录、搜索、商品 / RFQ 页面、网页表单、后退、前进、刷新、当前标签和链接复制。
Agent 能力
扫描与分析 RFQ、生成草稿、确认后回填及逐单提交。打开窗口和只读检测都不会开始报价。
当前范围
Alibaba 专用的单窗口浏览器；暂未提供多标签、扩展安装、书签或下载管理界面。外部网站请使用日常浏览器。

    这些状态是什么意思？
    当前记录
    显示当前工作列表中的记录；已归档草稿需单独筛选查看。
    待确认价格或规格
    已读到买家需求，但缺少本次 RFQ 可用的当前销售价格，或至少一项影响报价的关键规格未确定；可查看图片和历史线索，再人工核实。
    有金额，条件待确认
    已有金额，但仍依赖未确认的条件；不能直接提交。
    价格已确认，待审核
    规格匹配已批准价格规则，或这条 RFQ 的当前售价已由操作员核实；金额和拟回复完整，仍需逐单审核。
    已填报价表，未提交
    应用记录了浏览器表单回填，仍需核对页面并确认是否提交。
    已确认提交成功
    Alibaba 页面显示提交成功，且本地保存了提交状态。
    已归档草稿
    仅从当前工作列表移出，原始记录仍保存在本机。

    清单中的售价列留空；填写现价后可读取 CSV，逐条核对并保存本地草稿。
