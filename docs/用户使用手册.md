# RFQ 助手｜快速使用

使用前准备：联网、Alibaba 账号，以及软件提供者发放的**云端服务令牌**。安装包不含令牌；默认云端模式无需安装 Claude 或填写 GLM Key。

1. **安装软件**：Mac（Apple Silicon）打开 `.dmg`，把「RFQ助手」拖入“应用程序”；Windows（x64）双击 `.exe` 安装并打开。
2. **设置令牌**：左侧「设置 → 模型服务」，在「服务令牌 / 模型 API Key」填入令牌，点击「保存设置」和「测试模型连接」。需要识别图片时，再点击「测试 OCR 识别」；云端 OCR 默认复用同一令牌。
3. **登录 Alibaba**：左侧「浏览器 → 打开阿里巴巴浏览器」，在应用自带的窗口里登录，打开 RFQ 列表，确认账号状态显示已登录。
4. **分析需求**：左侧「报价 Agent」选择监控品类和发布时间范围，保持默认「仅生成报价话术」，点击「运行一轮分析」。只想查看新 RFQ 可点「只扫描 RFQ」；需要重复检查可点「持续监控」。
5. **核对结果**：在「RFQ 报价记录」选一条，核对买家原文、规格、图片、当前售价依据、交货地点和拟回复。「待确认价格或规格」「有金额，条件待确认」仍需人工核实；草稿不会自动发送。确需报价时，切换「逐单浏览器报价」，逐单确认回填；正式提交前再次核对并输入该 RFQ 的完整 ID 确认。

关闭窗口后软件仍可在后台运行；要结束监控，请在应用菜单选择「退出并停止任务」。每台电脑的令牌和数据保存在各自本机；令牌在本机加密保存。
