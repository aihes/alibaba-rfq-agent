02 / AGENT

报价 Agent

本机任务 · 单任务运行

检测、扫描、报价分级控制。先确认环境就绪，再按模式扫描 RFQ：仅产出报价话术，或经人工逐单确认后操作浏览器报价。
应用设置 · 首次使用先配置模型

填写模型服务后保存，再安装下方插件并登录 Alibaba。模型连接测试只发送固定文本，会产生少量 API 用量。

分析时需求文本会发送到所选模型；开启 GLM OCR 后，RFQ 图片会发送到智谱识别，按服务用量计费。密钥保存在本机，保存后不回显。

迁移已有 CASE

选择原项目的 data 文件夹，导入报价、附件和来源材料。已有同名数据不会被覆盖。

01 / ENV

环境检测

建议用专用 Chrome 配置运行 Agent，只在该配置启用 Midscene Bridge。日常办公用其他浏览器或主配置；扫描会切换 Alibaba 标签页。

进入本页自动检查本地环境；浏览器开关开启且无运行任务时才检测连接。

—
首次使用：安装 Midscene 插件

安装包已放在本项目中。首次安装按以下步骤操作，后续启动直接使用。

正在读取本地安装资源…

  1. 准备插件目录启动时自动准备；下方显示就绪后，复制目录。
  2. 在 Chrome 中加载插件复制下方地址到 Chrome 地址栏打开，开启右上角「开发者模式」，点击「加载已解压的扩展程序」，选择第 1 步的文件夹。 Mac 选择文件夹时按 ⌘⇧G，粘贴插件目录并回车，再点击「选择」。
  3. 打开 Bridge Mode 并检测在 Chrome 右上角拼图菜单固定并打开 Midscene.js，进入「Bridge Mode」。开启下方浏览器开关并重新检测；插件询问连接时点击「Allow」，同时确认 Alibaba 已登录。

准备文件不会安装插件或开启浏览器控制。

下载项目内的官方 ZIP 安装包 ↗

安装后请保留插件目录，Chrome 会继续使用这里的文件。
