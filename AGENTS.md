# Repository working rules

## Software package submission and upload

- When changing or packaging this app, keep the changes and generated packages local by default. Do not automatically run `git commit`, `git push`, create a release/tag, or upload Windows/macOS packages to GitHub Release assets.
- Wait until the user explicitly asks to upload the software package before committing, pushing, tagging, or uploading that package. Requests to modify, test, or build the app do not authorize those actions.
- If the user explicitly authorizes a specific submission or upload action later, follow that instruction for its stated scope.
